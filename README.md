# MorseCodeDecoder
A project that you can create to decode morse just by clicking or holding a button to convert into morse code.
Required:
1) 0.96-inch OLED Screen
2) ESP32C3 SuperMini
3) Button
4) Charging Module with Step Up Boost Module (https://www.amazon.com/dp/B0BJYRGZR4?plpRedirect=mhFallback&ref=clp_hp_h_pc)
5) Battery e33c (450mah )
